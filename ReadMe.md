# cbutter Firmware for Flipper Zero

## What is this?

This is a custom firmware build for Flipper zero that adds preset apps, and different pictures.

## How can i add an app to the official release?

Make a pull request.

## Who is the smily face guy?

His name is David. He wont hurt you
(yet.)

## What apps are included?

-Everything from Flipper's official firmware
-Enhanced SubGHz Chat

More coming soon!
